# MAA MALA™ - Modern React & Instagram Reels Showcase

A modern, responsive single-page web application featuring short-form video reels, Framer Motion animations, Tailwind CSS glassmorphism, client testimonials, and dark mesh ambient themes.

![MAA MALA Logo](public/images/logo.png)

---

## 🚀 Features

- **Floating Glass Navbar**: Sticky `rounded-3xl` glass header with Framer Motion hover states & responsive mobile drawer menu.
- **Interactive Hero Section**: Animated status badge, bold gradient typography, CTA buttons, and metric highlights.
- **Instagram Reels Showcase**: Horizontal momentum scroll carousel, category filter pills (*Viral, Tech, Design, Lifestyle*), Instagram card layouts, like & comment stats, and a fullscreen video preview modal with play/pause and mute/unmute controls.
- **Community Feedback & Testimonials**: Viewport scroll-triggered staggered card entrance (`whileInView`), 5-star ratings, user avatars, verified badges, and soft hover lift effects.
- **Minimalist Footer**: Brand logo, social icons with spring hover animations, back-to-top button, and copyright notice.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v3 (Custom dark mesh theme & glassmorphism)
- **Animations**: Framer Motion
- **Icons**: Lucide React + Custom SVG Brand Icons

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/IsacSmile/maa-mala.git
cd maa-mala

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build for Production
```bash
npm run build
```
